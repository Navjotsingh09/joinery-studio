# Plinth, wall-unit axes and DWG import - 8 October 2026

- Plinths are thin panels rather than solid full-depth blocks. Floor cabinets default to a front panel; islands default to four panels. Inspector checkboxes choose front/back/left/right independently. Zero-height and None plinths draw nothing. Overall entered cabinet height continues to include plinth height; changing plinth height does not change total unit height.
- Selecting a wall cabinet chooses Y movement so its vertical 3D handle is immediately available. X and Z remain available in the Axis control. Elevations and numeric Height Y support vertical placement; Top plan cannot represent vertical dragging. Locked cabinets and exploded views still disable transforms.
- DWG and DXF share the measured reference workflow. DWG decoding happens locally in a disposable module worker using LibreDWG WASM, with an 8 MB limit and 60-second timeout. All supported DWG layers, including hidden layers, are available for selection. Unsupported 3D solids/annotations are not editable kitchen geometry. Failed decoding retains the previous reference and project.
- A real LibreDWG Polyline sample converted from 179491 bytes to 343651 bytes of DXF. The app parsed one polyline, detected inches and produced a measured reference. This proves that sample; it does not certify every AutoCAD version, proprietary object or customer drawing.
- Regression tests verify thin front/return panel dimensions, preserved total unit height, DWG signature validation, worker cleanup and decode errors. Full suite and Next production build form the release gate.
